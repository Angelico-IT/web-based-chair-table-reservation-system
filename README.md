# 🪑 Jun Mar Chair's and Table's Reservation System

A web-based reservation system developed as our Bachelor of Science in Information Technology (BSIT) Capstone Project. The system streamlines the reservation process for chairs and tables, allowing customers to book online while enabling administrators to efficiently manage reservations.

---

## 📖 Project Overview

The Jun Mar Chair's and Table's Reservation System was designed to replace manual reservation methods with an online platform. It provides customers with a convenient way to reserve chairs and tables for events while giving administrators tools to monitor bookings, manage customers, and organize reservations.

---

## ✨ Features

- User registration and login
- Online chair and table reservation
- Reservation management
- Admin dashboard
- Customer information management
- Responsive web interface
- Database integration using MySQL

## 🚀 Installation

1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL.
4. Import the provided SQL database into phpMyAdmin.
5. Open your browser and visit:

```
http://localhost/WEB SYSTEM/
```
